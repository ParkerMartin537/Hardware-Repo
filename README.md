Verification Confirmation
The instructions below can be used to verify the hardware designs against my GPG key to ensure that everyone knows who the original creator is and to make sure no mimicking designs are done. 
1. gpg --import public-key.asc - This command allows you to import the public key on your device. You can run this command in PowerShell or the command terminal. 
2. gpg --verify "SSD Memory Design.pdf.asc" "SSD Memory Design.pdf" - This command allows you to verify the signature using the public key specifically for the SSD memory design. Make sure to adapt the file path to where the files are located on your device.

Other document verification commands:
1. gpg --verify "Cache Memory Design.pdf.asc" "Cache Memory Design.pdf"
2. gpg --verify "RAM Memory Architecture.pdf.asc" "RAM Memory Architecture.pdf"
3. gpg --verify "GPU Memory Architecture.pdf.asc" "GPU Memory Architecture.pdf"
